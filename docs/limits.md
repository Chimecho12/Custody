# 한계 (첫 페이지에 실을 문장)

1. 이 서비스는 중개자의 **기밀성 위반을 탐지하지 못한다.** 무결성·귀속·완전성만 다룬다.
2. 모든 영수증은 `security_mode = "evaluation"`, 증명 문서는 `mock`, 모든 판정의 보증은 최대 `air-local` 이다. TEE 출처를 주장하지 않는다. 이를 만드는 코드 경로가 없다.
3. 제3자는 실시간 차단을 하지 않는다. 차단은 **참여자(U, 선택적으로 M)의 집행 모듈**이 자기 정책으로 한다. 아무 당사자도 협조하지 않으면 가능한 방어는 매우 제한된다.
4. 아티팩트 해시 일치는 실행 일치가 아니다. 통계적 실행 검증(로그확률 기반)은 **미구현**이다.
5. 등록 시각은 발생 시각의 상한이지 발생 시각이 아니다. 수집 순서는 인과 순서가 아니다.
6. Merkle 트리·등록 영수증·체크포인트 앵커는 신뢰 기준점 대비 변경을 드러낼 뿐 조작 불가를 뜻하지 않는다. 앵커는 파일 기반 목격자 **모사**다. 트리·헤드·앵커는 "제시된 자료가 일관적인가" 만 답한다. "제시해야 할 자료를 다 제시했는가" 는 제출자가 등록 때 받아 **보관한 영수증**의 포함 검사로만 답할 수 있고(S18), 영수증을 보관하지 않은 감사자에게 누락은 보이지 않는다. 시뮬레이션의 U 와 데스크톱 Agent 는 영수증을 보관하고 매 감사에서 이 검사를 강제한다. R·M 이 제출한 항목의 누락은 R·M 이 자기 영수증을 보관·제출해야 보인다 (미구현).
7. R 과 M 이 공모해 일치하는 거짓 진술을 내면 현재 증거 구조는 위반을 보지 못한다 (S15). 위협 모델 TM1 밖이다.
8. 인센티브 양립('정직한 참여자의 효용 > 연동 비용')은 가설이다. 정산·유인 시뮬레이션은 미구현이다.
9. 스트리밍 응답의 청크 단위 검증은 미구현이다. 최종 응답 해시만 다룬다.
10. 응답 변환은 무변환(identity) 정책만 재계산 가능하다. 요청 변환은 identity 와 공개 결정적 변환 1종만 재계산한다. 비공개 변환은 '선언 확인·관계 미검증' 이다.
11. 투명성 로그는 1 인스턴스다. 같은 운영자의 이중 로그는 신뢰 분산이 아니므로 넣지 않았다. 독립 운영 목격자 연동은 후속이다.
12. 매니페스트는 사용자가 선언한 요청의 결손을 찾을 뿐 R 의 숨은 호출 전체를 복원하지 못한다. R 의 `refused` 선언만으로 실제 미실행을 확인했다고 표시하지 않는다.
13. 기본 진술 형식은 여전히 **자체 JSON 프로파일**이다. 여기에 더해 같은 진술을 RFC 9052 COSE_Sign1 (alg -8 EdDSA, CWT 클레임은 RFC 9597 라벨 15)과 RFC 8949 결정적 CBOR 로 내보낼 수 있고, `python runtime.py conformance` 가 적합성 벡터를 실제로 실행한다 (현재 pass 30 · partial 1 · absent 8 · fail 0). 제3자 구현 2종(`cbor2` 5.x, `pycose` 1.1)이 같은 바이트를 읽는지도 교차 검증한다 — cbor2 는 canonical 재인코딩이 바이트 동일한지, pycose 는 서명을 검증하고 변조된 서명을 거부하는지. 두 도구가 없으면 '미실행' 으로 남고 주장 상태가 `planned` 로 내려간다. `cosign`·`pyscitt` 은 대상이 달라 쓰지 않는다 (전자는 sigstore 번들, 후자는 CCF 로 도는 SCITT 서비스). 여전히 **표준 준수 전체를 주장하지 않는다** — 다중 목격자 가십, 해지 클레임, TEE 증명 결합은 미구현이다.
14. Ed25519 순수 Python 구현은 상수 시간이 아니다. 실제 비밀키를 다루는 배포에서는 검증된 라이브러리를 써야 한다. 기본 보관은 여전히 로컬 파일(Windows 는 DPAPI)이므로 서명 순간 사설키가 프로세스 메모리에 평문으로 존재한다. `itx.keys.CommandSigner` 로 외부 서명자(KMS·HSM)에 위임하면 사설키가 이 프로세스에 들어오지 않는다. **단, 순수 Ed25519 는 메시지 전체에 서명하므로 '해시만 전송'은 prehash 방식에서만 참이다** — 무엇을 보내는지는 `payload_form` 에 기록되어 화면에 그대로 표시된다.
15. 지연 수치는 고정 상수(홉 20 ms, 서명 2 ms, 등록 15 ms 등)다. 실제 네트워크·모델·가용성 측정이 아니다. 18 시나리오 × 3 모드 = 표본이 작으므로 비율은 시나리오 비교용이다. 화면의 홉 지도 재생은 실측된 전송·수신 시각 사이를 이 상수 비율로 나눈 **추정**이며 패킷 캡처가 아니다. 그렇게 표기한다.
16. 모형 모델은 결정적 문자열 변환이며 LLM 이 아니다. S16 의 '지시를 따르는 모델' 도 교육용 장치다. 실제 소형 LLM 연동은 후속이다.

## 주장 상태

| 표기 | 이 저장소에서의 해당 |
|---|---|
| `measured_result` | 없음 |
| `mock_result` | artifacts/ 의 모든 수치. T 기여 실험(로컬만 vs U+T)도 여기 속한다 — "사용 전 차단은 T 와 무관, T 는 실행 전 거부·탐지 기록·감사 발견을 더한다" 는 모형 모델·단일 PC 결과다 |
| `verified_external` | 기획 문서가 절 번호와 함께 확인한 표준 조항. 코드 주석의 RFC 인용은 이를 옮긴 것. RFC 8949 부록 A 시험 벡터는 `tests/test_cose.py` 가 직접 대조하고, COSE_Sign1 서명은 `pycose` 가 검증한다 |
| `planned` | 다중 TS, 실앵커, 통계 검증, 스트리밍, 정산 시뮬레이션, 실제 모델, TEE 증명, 외부 도구 상호 운용 확인 |
| `hypothesis` | 인센티브 양립, 시장 수요 |
